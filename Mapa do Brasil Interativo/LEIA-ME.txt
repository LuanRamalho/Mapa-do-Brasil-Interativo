MAPA INTERATIVO DO BRASIL
Instale Python 3.10 ou superior.

Abra o Prompt de Comando na pasta do programa.

Instale as dependências:

py -m pip install -r requirements.txt

Execute:

py mapa_brasil_interativo.py

Na primeira execução, o programa baixa a malha GeoJSON das 27 unidades federativas e cria o arquivo:

brasil_estados.geojson

Depois disso, o arquivo local é reutilizado.

O programa também cria:

mapa_brasil_interativo.html

O HTML é aberto automaticamente no navegador padrão.

COMO FUNCIONA
O mapa contém 26 estados + Distrito Federal.
Passe o mouse sobre qualquer unidade federativa.
O tooltip mostra: Estado Sigla População conforme Censo Demográfico 2022 do IBGE
Clique em uma unidade para abrir um quadro adicional com os mesmos dados.
Não utiliza WebSocket, servidor local ou framework de tempo real.
